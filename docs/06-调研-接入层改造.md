| 项目 | Stars | 最近 push | 定位 | 适配度 |

## 四、4 层改造设计(定稿待确认)

```
upload API
   │
   ▼
[L1 格式路由] router.py (新增)
   ├─ 扩展名粗分: pdf/docx/xlsx/csv/txt/md/img/audio
   ├─ PDF 判定: pypdf 抽 3 页试提取
   │    有文字 → parse_text 直读路径(零成本)
   │    0 文字 → 扫描版 → OCR 路径(pypdfium2 逐页渲染)
   └─ 产出: route = "direct" | "ocr" | "tabular" | "asr"(预留)
   │
   ▼
[L2 分级解析] parser.py (增强,保留原函数)
   ├─ direct: 现状 pypdf/python-docx 不动
   ├─ ocr: qwen-vl-ocr 逐页(批量,保留 [页码 N] 前缀)
   ├─ 降级链: 云端OCR → (失败/无额度) 标"待处理"不硬来
   └─ 大文件: 后台异步任务 + 解析状态机(排队/解析中/完成/失败)
   │
   ▼
[L3 统一中间格式] (parser 输出现状基本兼容)
   ParsedDoc{content, metadata{filename,pages,format,route,parse_method}}
   页码标记进 chunk 已有机制,不动 chunker
   │
   ▼
[L4 质量门禁] gate.py (新增)
   ├─ 文字量 < 200 字/页均 → 拦截,标"疑似空文档"(352字测试docx就是目标)
   ├─ 文件哈希去重(uploads 里现存 2 份重复高级一本通)
   └─ 全 0 文本 → 拒绝入库并报告原因,不再静默成功
```
