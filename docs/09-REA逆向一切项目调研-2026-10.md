## 1. 它是什么（一句话 + 架构）

**一个 MCP server + CLI，把成熟逆向工程工具链接给 AI coding agent**（Claude Code/Cursor/Codex/Gemini CLI/Windsurf），让 agent 对没有源码的软件做"行为→代码→二进制"三级调查，产出**带证据和局限声明**的结论，再用它指导复刻功能。口号"See a feature you like. Understand how it works, down to the binary level."

```
Agent / 终端
  └─ REA (CLI + MCP, npm rea-agents, TS, MIT, 本地运行)
       ├─ Native: Hopper / Ghidra / IDA（可复用已有安装，可选装 Hopper）
       ├─ JS/Electron: 静态分析（无需原生引擎）
       ├─ .NET assemblies
       ├─ Web: Chrome DevTools Protocol 被动观测
       ├─ Artifact: ZIP/APK/IPA/ASAR/MSIX 清点
       └─ Process capture: 受控终端会话行为捕获
  → 输出: Evidence records（证据+unknown 都返回）
```

- 规模：README 宣称 **139 个 MCP tools**，三阶段调查模型（app behavior → code → native binary）。
- 卖点差异化：不是"LLM 包装"，每条结论带**证据链和 limitations**（Medium 分析文原话强调这点）；分析全部本地跑，不上传。
- 作者：morluto（单人主导，hotmail 个人邮箱，无公司背书——OpenClaw 同款个人爆款叙事）。

## 2. 为什么火（社会心理，不是技术）

1. 踩中"closed source is no longer a moat"焦虑叙事——Medium 那篇标题直接用这句。
2. MCP 生态爆发期的典型形态：**老工具（Ghidra/Hopper 存在 20 年）× 新协议（agent 可直接调用）= 新物种**。工具本身没有发明任何逆向技术，发明的是"让 agent 会用逆向工具"的分面。
3. 病毒式分发标配：`npx rea-agents setup` 一行装 + 16 语言 README + Discord + Trendshift 徽章运营。

## 3. 风险与边界（宣传不会告诉你的）

- **法律**：工具 MIT ≠ 使用行为合法。逆向竞品受 EULA/著作权法/反不正当竞争法约束（美国 Breyner v. Sandel 类判例、中国软著条例 17 条"合理使用"极窄）。用它"理解友商功能然后复刻"，在商业环境是高危动作，**甲方场景严禁默认使用**。
- **单人项目风险**：139 tools、614 open issues、无组织背书——维护可持续性存疑；npm 仅 3 个月历史，需防 typosquat（装错包名=供应链攻击，rea-agents 是唯一的正牌名）。
- **能力边界**：强混淆/加壳/服务端逻辑它无能为力（功能在服务端的 app，逆向客户端=只拿到 API 壳）。"anything"是营销词。

## 4. 对我们三个具体借鉴点（与知识库 V2 无关，属工程经验）

| # | 借鉴 | 用到哪 |
|---|---|---|
| 1 | **Evidence+Limitations 输出格式**：每个结论附证据引用和"我不知道什么" | 正好接上 V2 方案 §1.4"已检索 N 篇，另有权限受限文档未纳入"——同一设计哲学：系统必须声明自己的盲区。可把引用块升级为"证据+置信+局限"三件套 |
| 2 | **三阶段调查模式**（行为→代码→二进制 = 先便宜后昂贵的递进检索） | 招投标打包 AI 拆查询可参考：先元数据/标题匹配（便宜），不够再全文检索，最后才 LLM 逐篇判断 |
| 3 | **MCP 作为能力封装范式** | 我方 Hermes 已支持 native-mcp；若未来要把本系统检索能力给别的 agent 用，做成 MCP server 比做 REST 更快被生态接入 |

## 5. 结论

- 项目真实、工程素质不错（本地运行、证据链输出、复用成熟引擎而非重造），但**星数叙事掺水、单人项目、使用场景法律雷区**三条都在。
- 不建议引入任何业务链（与我们做的知识库/面试系统无交集）；借鉴点 1 是白捡的设计升级，可并入 V2 方案 §1.4 修订清单（编号 R5，待老板拍板）。
- 对自媒体标题的教训：**先查 API 再信"最恐怖"**。此条已被本次实测再次验证（视频说周增 14 万 vs 实际半年累计 18.6 万）。
